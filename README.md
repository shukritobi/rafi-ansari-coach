# Rafi Ansari Coach Website

Responsive one-page personal brand website concept for Rafi Ansari, Regional Business Coach.

## Included

- Premium hero and positioning
- Business coaching and growth strategy services
- Catalyst Business Coaching Programme
- Four-step coaching approach
- Regional positioning for Singapore and Malaysia
- Singapore and Malaysia enquiry links
- WhatsApp and social links
- Responsive mobile navigation
- Lightweight scroll reveal interactions

## Deployment

Static site. No build command is required.

Recommended options:
- GitHub Pages
- Cloudflare Pages
- Netlify

For Cloudflare Pages, connect `shukritobi/rafi-ansari-coach`, use branch `main`, leave the build command blank and set the output directory to `/`.

## Notes

This is an outreach concept assembled from publicly available business information. Verify contact details and final production copy with the client before using it as an official site.
